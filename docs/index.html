02 / Telegraph integration

Live external intelligence, not settlement authority

The live integration uses a payment-aware x402 client to retrieve Telegraph /trade-context Miner intelligence. The returned intelligence is adapted and normalized before entering the local deterministic decision boundary.

Live Miner path

Telegraph /trade-context is accessed through the x402 payment-aware mining agent.

Provider adapter

Telegraph data is converted into provider-independent intelligence before decision evaluation.

03 / Deterministic decision

Unknown evidence is not silently converted into approval

Real economic intelligence

The demonstrated workflow uses Base RPC and CoinGecko for observed blockchain/economic inputs. Live values can vary between runs.

Regulatory evidence

The demonstrated India → Brazil path has regulatory evidence marked UNKNOWN. The decision engine therefore returns an incomplete-data result rather than inventing permission.
